# Portfolio screenshot sources

Captured or retrieved on 27 October 2026. Images are included as product illustrations, not evidence of adoption, revenue or engineering impact.

## Arievo

`arievo-workout-light.png` and `arievo-profile-dark.png` show the application's actual React Native screen components in an isolated local Expo web preview. The workout dashboard uses light mode and the profile uses dark mode.

All accounts, names, relationships, workout history and statistics in these captures are synthetic demonstration data. The preview did not use real accounts or connect to a backend. These are web-rendered UI previews, not native-device or production screenshots. The source application repository was not modified.
